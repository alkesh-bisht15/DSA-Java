# Time and Space Complexity

## Time Complexity

Time complexity describes how the running time of an algorithm grows
as the input size increases.

### Common Complexities

| Complexity | Name |
|---|---|
| O(1) | Constant |
| O(log n) | Logarithmic |
| O(n) | Linear |
| O(n log n) | Linearithmic |
| O(n²) | Quadratic |
| O(2ⁿ) | Exponential |
