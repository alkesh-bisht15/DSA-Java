# Array Basics

This section contains the basic array problems I learned and implemented
during DSA Day 1.

## Problems Covered

| Problem | Time Complexity | Space Complexity |
|---|---:|---:|
| Find Maximum | O(n) | O(1) |
| Find Minimum | O(n) | O(1) |
| Linear Search | O(n) | O(1) |
| Reverse Array | O(n) | O(1) |
| Second Largest | O(n) | O(1) |
| Check if Array is Sorted | O(n) | O(1) |
| Count Occurrences | O(n) | O(1) |

## Concepts Practiced

- Array traversal
- Comparing array elements
- Maintaining variables while traversing
- Searching
- In-place array modification
- Finding maximum and minimum
- Checking conditions across an array
- Counting occurrences
- Time complexity analysis
- Space complexity analysis
